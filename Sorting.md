## Insertion Sort

A stable sorting algorithm because it preserves the relative order of the elements.
The best case time for Insertion sort is O(n). Example: 1,2,3,4. We just have to make one comparison for each element. For 4 elements there are 4 comparisons.

Worst case: 4,3,2,1 Comparisons 1 + 2 + 3 + 4 (c.n^2 = 1/2 n^2)
n^2 = 4^2 = 16

| Algorithms              | Big-O Time |
| ----------------------- | ---------- |
| Insertion Sort (stable) | O(n^2)     |
| Mergesort (stable)      | n logn     |
